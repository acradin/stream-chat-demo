# 웹 체험 영상

사용자가 웹 데모용으로 제공한 영상의 브라우저 재생용 사본입니다.

| 파일 | 원본 파일명 | 길이 | 형식 |
| --- | --- | --- | --- |
| demo-01.mp4 | KakaoTalk_20261031_194012444.mp4 | 약 20.18초 | H.264, 1280×720, AAC |
| demo-02.mp4 | KakaoTalk_20261031_192905184.mp4 | 약 3.57초 | H.264, 1280×720, AAC |
| demo-03.mp4 | KakaoTalk_20261031_192636544.mp4 | 약 8.75초 | H.264, 1280×720, AAC |

`demo-01.jpg`는 같은 영상의 2초 지점 포스터입니다.
`demo-02.jpg`, `demo-03.jpg`는 각 영상의 1초 지점 포스터입니다.
원본 HEVC 파일은 변경하지 않았습니다. 사본은 H.264 CRF 24, yuv420p, AAC 96k, faststart로 변환했습니다.
영상 목록은 `src/lib/demoVideos.ts`에서 관리합니다.
