# 방송 화면 실시간 AI 실험

이 폴더는 개발자용 비교 실험입니다. **일반 사용·수동 테스트는 [데스크톱 오버레이](../../DESKTOP.md)의 버튼 캡처 / 실시간 화면 모드에서 진행합니다.** 프로젝트 루트의 `start_desktop.cmd` 또는 설치본을 실행하세요. 아래 웹 UI는 실험 재현용으로 남겨 둡니다. 로그인, 치지직 전송, 서버 배포, 음성 입력은 포함하지 않습니다.

## 실행

1. 이 폴더의 `start.cmd`를 실행합니다. 프로젝트의 기존 `.venv`를 사용합니다.
2. Chrome 또는 Edge에서 <http://127.0.0.1:8768>을 엽니다.
3. 페르소나, 판단 간격, 실험 시간을 선택합니다. 처음에는 **30초**로 시작하면 됩니다.
4. **방송 화면 선택하고 시작**을 누르고 방송이 재생되는 창이나 탭을 공유합니다.
5. AI가 시각적 변화에 반응하면 오른쪽 채팅에 표시됩니다. **중지**, 브라우저의 공유 중지, 탭 종료, 시간 제한으로 끝납니다.

화면 선택은 매번 사용자가 직접 합니다. 방송 화면을 계속 재생해 두세요. 배경 탭에서 타이머가 느려지면 프레임 전송도 느려질 수 있습니다. 이 실험 화면 자체를 공유하면 화면이 반복해서 비칠 수 있습니다.

기존 `backend/.env`의 `OPENAI_API_KEY`를 자동으로 읽습니다. 키를 다시 입력할 필요가 없고 브라우저로 전달하지 않습니다. 실험 모델은 **`gpt-realtime-2.1`**이며 기존 앱의 `OPENAI_MODEL` 설정과 분리되어 있습니다. 필요한 경우 이 폴더에 `.env.example`을 복사한 `.env`를 만들어 `REALTIME_MODEL`만 바꿀 수 있습니다. 환경 변수, 실험 `.env`, 기존 `backend/.env` 순으로 우선합니다.

수동 실행은 프로젝트 루트에서:

```powershell
& .\.venv\Scripts\python.exe -B -m experiments.realtime_video --provider openai
```

연결·화면 표시만 확인할 때는 `--provider mock`을 사용합니다. Mock은 화면을 해석하거나 OpenAI를 호출하지 않으며 대기와 고정된 테스트 문구를 번갈아 반환합니다. 별도 패키지 설치는 필요하지 않습니다.

## 동작과 제한

- 선택한 화면을 초당 최대 1장, 긴 변 최대 1280px의 JPEG로 전송합니다. 동영상 파일을 직접 입력하는 방식이 아니라 **연속 이미지**를 같은 Realtime 연결로 보냅니다.
- 최근 6장을 보고 반응 여부를 판단합니다. 진행 중인 판단에 필요한 프레임은 응답이 끝날 때까지 유지하고, 이후 오래된 프레임을 삭제합니다.
- 판단 간격은 3·5·10초입니다. 한 번의 판단이 끝난 뒤 다음 간격을 기다리므로 실제 주기는 선택한 간격보다 길어집니다. 동시에 여러 판단을 실행하지 않습니다.
- 반응할 변화가 없으면 `WAIT`, 변화가 있으면 근거 프레임을 지정한 `REACT`를 반환합니다. 근거가 8초보다 오래됐거나 채팅 간격이 8초 미만이거나 최근 문구와 같으면 표시하지 않습니다.
- 기본 페르소나 4개와 상황 설명을 사용할 수 있습니다. 화면 문구와 상황 설명은 관찰 데이터로 취급하며, 소리를 들었다고 주장하거나 보이지 않은 대사를 만들지 않도록 지시합니다.
- 표시되는 판단 시간은 **API 응답 생성에 걸린 시간**입니다. 방송 장면 발생부터 채팅 표시까지의 전체 지연을 뜻하지 않습니다.
- 한 번에 한 세션, 최대 2분입니다. API 오류나 출력 검증 실패 시 중단하며 자동 재시도하지 않습니다. 중지 시 공유 트랙과 서버의 API 연결을 닫습니다.
- 화면 공유는 `audio: false`로 요청하며 음성 데이터 메시지도 거부합니다. 마이크·방송 오디오를 받지 않습니다.
- 실행 중 선택한 화면은 OpenAI로 전송되고 API 사용량이 발생합니다. 실험 UI에는 API 키나 OpenAI 청구 사용량을 표시하지 않습니다. 기존 서비스 사용량 기록에도 합산하지 않습니다.
- 일반 실험은 화면 파일·채팅 기록을 로컬에 저장하지 않습니다. OpenAI 측 데이터 처리는 해당 API 계정의 설정을 따릅니다. 서버는 `127.0.0.1`에만 열립니다.

화면만으로 판단하므로 대화 위주의 방송, 빠른 움직임, 작은 글자는 놓칠 수 있습니다. OpenAI 연결·출력 검증은 `backend/realtime_provider.py`를 데스크톱과 공유합니다. 데스크톱은 인증된 공통 서비스 API와 서비스 사용량을 사용하며, 이 개발 웹 실험의 인증·사용량은 별개입니다.

## 비용 비교와 응답 형식 수정

직접 만든 합성 장면으로 실제 모델을 비교한 결과와 재현 명령은 [EXPERIMENT_RESULTS.md](EXPERIMENT_RESULTS.md)에 있습니다. 자유 텍스트 JSON 대신 지정 함수 호출의 인자를 검증하도록 바꿨습니다. 설명 텍스트는 판단 JSON에 합치지 않습니다.

## 검증

자동 테스트는 합성 이미지와 로컬 WebSocket 서버만 사용합니다.

```powershell
& .\.venv\Scripts\python.exe -B -m unittest discover -s experiments/realtime_video -p 'test_*.py' -v
```

실제 API 연결을 별도로 점검하는 명령입니다. 실행할 때마다 유료 API 판단을 1회 요청합니다. 사용자 화면 대신 파란 팀 3점, 빨간 팀 1점에서 4점으로 변하는 가상 점수판만 전송합니다.

```powershell
& .\.venv\Scripts\python.exe -B -m experiments.realtime_video.live_check
```

이 명시적 점검만 `runs/live_*/report.json`에 합성 입력에 대한 모델 응답·소요 시간을 기록합니다. `runs/`는 기존 Git 제외 규칙에 포함됩니다. 실제 방송 화면 공유 UI는 사용자가 직접 확인하는 범위로 남겨두었습니다.
